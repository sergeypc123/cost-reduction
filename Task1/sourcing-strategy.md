# Аудит возможностей и Sourcing Strategy

## Что дублируется или дорого стоит

| Возможность | Проблема |
|---|---|
| Кассовое обслуживание | В каждом магазине свой толстый клиент и сервер с платными лицензиями Windows Server и SQL. Отказ диска останавливает магазин на 4–6 часов (INC-8433) |
| Приём платежей | Драйвер каждого терминала встроен в кассовое ПО. Новый тип терминала означает 3 недели разработки и пересборку кассы (INC-8415) |
| Мастер-данные номенклатуры | Номенклатура сводится вручную в Excel, 80% позиций смотрят глазами, 15% ошибок на кассе |
| Программа лояльности | У купленных магазинов ведётся в тетрадках, у своих — онлайн-запросом без офлайн-режима (INC-8402) |
| Расчёт премий продавцам | Считается локально в магазинах, хотя кадровый учёт уже ведётся в SAP. Функция дублируется |
| Печать ценников | Цены приходят ночью, ценники печатаются локально, расхождения между ценником и кассой |
| Приёмка от локальных поставщиков | У каждого магазина свой порядок и свои файлы |
| Инфраструктура и поддержка | Около 40% ИТ-бюджета уходит на серверы в подсобках и выезды инженеров |

Конкурентное преимущество сети — Smart Fulfillment (Click & Collect) и единый Promo Engine. Их не покупаем, а развиваем сами.

## Матрица Buy vs Build

| Возможность | Целевая модель | Решение | Почему |
|---|---|---|---|
| Кассовое обслуживание | **SaaS (Buy)** | Облачная касса (Cloud POS) на планшете | Стандартная функция, конкурентного преимущества не даёт. Убирает локальные серверы и лицензии |
| Программа лояльности | **SaaS (Buy)** | Облачная платформа лояльности, интеграция с Promo Engine | Типовая функция. Единая база клиентов вместо тетрадок, офлайн-режим из коробки |
| Печать ценников | **SaaS (Buy)** | Модуль Cloud POS: ценники формируются из единого прайса | Цена на ценнике и на кассе берётся из одного источника |
| Приёмка от поставщиков | **SaaS (Buy)** | ЭДО (СБИС, Диадок) + приёмка на планшете, данные в SAP | Типовой процесс, одинаковый для всех магазинов |
| Инкассация | **SaaS / аутсорсинг** | Сервис инкассации банка, учёт в SAP | Не профильная функция |
| Мониторинг и управление устройствами | **SaaS (Buy)** | MDM для планшетов и edge-устройств | Удалённое управление вместо выездов |
| Promo Engine | **PaaS (Migrate)** | Перенос в облако на managed Kubernetes и managed PostgreSQL | Уникальная логика промо, но администрировать серверы под неё самим незачем |
| Smart Fulfillment (Click & Collect) | **PaaS (Build in Cloud)** | Развиваем сами в облаке, managed БД и брокер сообщений | Главное конкурентное преимущество, нужна гибкость и масштабирование в пики |
| Интеграция данных и маппинг SKU | **PaaS + AI-сервис** | Облачная платформа интеграции, managed ML/LLM API, свои правила проверки (Task2) | Своя логика сопоставления, вычисления ИИ проще брать как сервис |
| Аналитика продаж | **PaaS** | Managed DWH (ClickHouse или аналог) | Не нужно держать своё хранилище |
| Слой интеграции с оборудованием (HAL) | **Build** | Свой лёгкий агент в магазине с адаптерами на SDK производителей (Task3) | Готового решения под наш парк терминалов нет, а сам слой небольшой |
| SAP ERP (товары, кадры, финансы) | **In-house / on-premises** | Остаётся в ЦОД компании | Миграция дорогая и долгая, на горизонте года даёт риск без выгоды. Вернёмся к вопросу при обновлении SAP |
| Расчёт премий продавцам | **In-house (консолидация)** | Убираем локальный расчёт, считаем в SAP HCM | Функция уже есть в SAP, дублирование просто убираем |
| Фискализация | **On-premises (в магазине)** | Фискальный регистратор с ФН остаётся в магазине, подключается через HAL | Требование 54-ФЗ: фискальный накопитель физически в точке продаж |
| Локальные серверы магазинов | **Вывод (Retire)** | Ликвидируются | Их функции переходят в Cloud POS и edge-агент |

## Ограничения при выборе облака

- Персональные данные покупателей из программы лояльности по 152-ФЗ хранятся в России, поэтому SaaS и облако выбираем у российских провайдеров (Yandex Cloud, VK Cloud, Cloud.ru).
- Для облачной кассы нужна поддержка нашего ОФД и работа без связи: это входит в требования к выбору поставщика.

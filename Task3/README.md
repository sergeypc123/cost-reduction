## Как решается проблема оборудования

В магазине остаются планшет, фискальный регистратор, терминал и небольшой Edge Hub (мини-ПК или Android-бокс). Облачная касса из браузера не может напрямую общаться с USB-портами, поэтому это делает HAL на Edge Hub. Он даёт кассе один и тот же API (`pay`, `refund`, `printReceipt`, `openShift`), а под ним работают адаптеры для конкретных моделей, написанные на SDK производителей.

Чтобы подключить купленный магазин с новыми терминалами, достаточно добавить адаптер и прописать профиль терминала в Payment Gateway. Edge Hub получает его через MDM. Кассовое приложение не меняется, поэтому 3 недели разработки из INC-8415 превращаются в 1–2 дня. Если для терминала адаптера ещё нет, терминал меняется на поддерживаемую модель из стандарта сети.

Edge Hub не хранит основных данных. Если он сломался, в магазин отправляется новый уже настроенный бокс, а кеш заливается из облака. Сервера, который нужно восстанавливать, больше нет.
